# Personas & Onboarding Checklist

Purpose: Provide a short, actionable checklist to ensure roles and responsibilities are communicated and enforced for each project.

- [ ] Confirm primary contacts for each role (Product Manager, Project Manager, Developer lead, UX Designer, QA Lead, DevOps Engineer, Security Champion)
- [ ] Document responsibilities and handoff points in project README or docs/
- [ ] Add role-specific acceptance criteria templates to docs/
- [ ] Ensure each role has a channel or contact method listed in the project README
- [ ] Include role responsibilities in project kickoff slide or kickoff doc
- [ ] Assign owners for the Risk Register, Release Checklist, and Retro action items
- [ ] Review and update personas on project onboarding checklist at the start of each quarter
